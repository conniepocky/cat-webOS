# Cat WebOS

This is a simple webOS inspired by the Frutiger Aero design style and of course featuring cats, for the Hack Club Stardance.

### Features

- Binary Cat Decoder: translates from 8 bit binary into denary, showing the user how it is translated 
- Random Cat Photo: uses an API to show a random cat photo when launching the app
- Notesapp: like a traditional notes app for taking notes

### How I made it

I used pure HTML, CSS and JavaScript to make it :) 

### How to view it?

See it running live on https://cat-webos.vercel.app/
